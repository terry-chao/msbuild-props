# msbuild-props

MSBuild user props for Visual C++ projects.
全局 UTF8 支持

## 安装

下载 [install.bat](https://raw.githubusercontent.com/terry-chao/msbuild-props/main/install.bat) 后双击运行即可。

脚本会自动从 GitHub 下载最新配置，并将 props 文件安装到：

```
%LOCALAPPDATA%\Microsoft\MSBuild\v4.0\
```

> 需要电脑上已安装 **Git** 和 **PowerShell 5.1+**（Windows 10/11 默认已内置）。
